# Taskleaf-Kanban 产品需求文档（PRD）

状态：作为验收基线；本地功能已实现并通过自动化测试，服务器私网部署已验证；匿名公网读写已获用户确认，公网页面及读取接口已通过外网验证。实际运行方式见 README 与 DEPLOYMENT.md。

## 1. 产品定位与目标

面向个人使用的轻量任务看板，将当前浏览器独立保存任务的方式升级为服务器统一保存。不引入数据库，不重构为复杂的团队协作产品。

已确认的使用方式：通过公网 IP＋端口访问，不要求域名。不同浏览器访问同一个服务，使用同一份任务数据。

核心问题：此前助手录入的任务只存在于其操作的浏览器环境，用户用 Edge 打开时不可见。升级后，服务器数据是唯一权威来源。

## 2. 已确认的边界

- 个人小项目；使用 JSON 文件持久化，不安装数据库。
- 保留现有页面与看板交互，无需引入 React、Vue 或 UI 组件库。
- 服务器运行后端，网页可以创建、修改和删除服务器保存的任务。
- 代码存入 GitHub，通过 GitHub Actions 构建并部署到用户服务器。
- 不使用 PM2，由 systemd 管理后端服务；Nginx 提供静态页面和 API 反向代理。
- 用户已授权本次开放公网匿名读写；提交和推送仍按任务单独确认，不迁移或清空真实数据。

## 3. 本期功能范围

### 3.1 保留看板功能

- 待处理、进行中、待验收、已完成四列。
- 创建、编辑、删除任务；标题必填，删除前确认。
- 描述、优先级、标签、截止日期等现有字段。
- 跨列拖拽、列内排序、搜索与优先级筛选。
- 已完成任务归档、按日期分组、恢复任务。
- 现有响应式布局和键盘操作支持。
- 右上角设置按钮收纳 JSON 导入导出，支持点击外部或 Escape 关闭。
- 右上角提供明暗主题切换，首次跟随系统，手动选择仅在当前浏览器记忆，不影响任务数据。

### 3.2 统一保存与反馈

- 页面加载时从后端获取任务；操作经后端确认后才显示保存成功。
- 刷新页面、重启后端、重新部署代码后，数据和排序保持。
- 明确区分加载中、加载失败、空看板、保存中、保存成功和保存失败。
- 保存失败时保留未提交输入并允许重试，不静默切换到浏览器本地保存。
- 多浏览器共享数据不等于实时协作：本期以浏览器刷新页面获取最新数据为准，不提供独立“刷新数据”按钮。
- 遇到旧版本修改时提示冲突并重新获取数据，不静默覆盖其他页面的修改。

### 3.3 JSON 导入导出与备份

- 提供 JSON 导出与显式导入，用于备份和跨服务转移任务。
- 不提供“迁移当前浏览器旧任务”按钮，不读取或删除旧 localStorage 数据。
- 导入前校验格式并显示预览；默认按任务 ID 去重，有冲突时提示，不默默覆盖。
- 未经确认不清空原有数据，不把演示任务当作用户任务自动导入。
- 全新服务器默认空看板；已有文件无法读取或损坏时应报错，不覆盖为空数据。
- 任务数据不提交到公开 GitHub 仓库，不随部署包发布。

### 3.4 助手录入工作流

- 用户给出任务清单时，助手按原意录入，不擅自执行清单中的工作。
- 信息不足以正确录入时先询问；非必填字段可留空，默认待处理、中优先级、无截止日期。
- 未确认的描述不自行扩写为新的工作要求。
- 助手必须操作用户使用的同一服务器实例，录入后重新读取验证。
- 对现有 Skill 的调整属于后续开发内容；本文不代表已经接通服务器。

### 3.5 公网匿名访问（已确认）

- 当前允许任何人通过公网 IP＋端口访问同一份任务数据。
- 所有访客均可查看、导出、新增、修改、删除、排序、归档和导入任务；不区分只读访客与管理员。
- 用户明确将身份验证和权限控制推迟；本期不加登录、密码或来源 IP 白名单。
- 当前使用明文 HTTP，无身份校验，不承诺任务保密或防恶意修改；不应录入敏感信息。未来认证及加密传输另行设计。

## 4. 不在本期范围

- 多租户、团队协作、角色权限和公开注册。
- WebSocket 实时协作、完整离线同步、自动合并冲突。
- 数据库、前端框架重写、微服务与容器编排。
- 每次修改任务自动提交 GitHub 或触发 CI/CD。
- 自动开始执行看板上的任务、定时提醒和外部平台集成。

## 5. 验收标准

| 场景 | 预期结果 |
| --- | --- |
| Chrome 新建任务，Edge 访问同一服务并刷新 | 看到同一任务及字段 |
| 编辑、拖拽排序、归档和恢复后刷新 | 状态与顺序正确保留 |
| 后端停止或写入失败 | 不误报成功，保留输入，可重试 |
| 两个页面基于旧数据先后修改 | 检测冲突，不静默覆盖 |
| 重启后端或再次发布代码 | 原有任务与归档仍在 |
| 数据文件损坏 | 明确报错，保留原文件，不初始化覆盖 |
| 同一份旧任务重复导入 | 不生成重复任务，冲突可见 |
| 备份恢复 | 可以恢复已备份任务并核对数量及字段 |
| 匿名访问页面和 API | 无需登录即可读取和修改；仍保留 Host、同源、格式与 revision 校验 |
| 助手录入任务后在 Edge 刷新 | 同一服务器中的任务可见 |
