查看 JSON 示例与 AI 提示词

id、title 必填。id 使用字母、数字、短横线或下划线；不同任务使用不同 ID，同一任务重试时保持 ID 不变。相同标题但不同 ID 仍会新增。

[
  {
    "id": "ai-blog-001",
    "title": "整理自媒体学习笔记",
    "desc": "",
    "pri": "medium",
    "st": "todo",
    "tag": "自媒体"
  }
]

可发给 AI：请把我的任务整理为 JSON 数组，只输出 JSON，不要 Markdown 代码围栏。每项包含唯一且稳定的 id 和原任务标题 title；其他字段可省略。可选 desc（描述）、pri（high / medium / low）、st（todo / doing / review / done）、tag（标签）、due（YYYY-MM-DD）。未指定时用中优先级、待处理，不编造任务要求。
